# UX Specification

## UX North Star

> Qual é a menor quantidade de informação necessária para o usuário tomar uma decisão melhor?

## Progressão

RESUMO → CONTEXTO → DETALHES → AÇÃO

## Princípios

1. Glanceable
2. Progressive Disclosure
3. Context First
4. Actionable
5. Predictable
6. Reversible
7. Calm
8. No Judgment

## UX financeiro

- Contexto antes de detalhe.
- Comparação sempre que relevante.
- Período explícito.
- Estimativas identificadas.
- Sinal + texto + ícone; não apenas cor.
- Mudança não é automaticamente boa ou ruim.
- Precisão proporcional à qualidade dos dados.

## Trust UX

Estados devem distinguir:
- Confirmado
- Importado
- Estimado
- Simulado

## Copilot

Não apresentar a IA como autoridade absoluta.
Mostrar dados usados, explicação e, quando aplicável, confiança e ações.

## Estados obrigatórios

- Loading
- Empty
- Error
- Partial
- Stale
- Permission denied
- Offline/degraded quando aplicável
