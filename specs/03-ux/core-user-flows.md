# Core User Flows

## Onboarding

```text
Welcome
 → Create account / Sign in
 → Create Workspace
 → Add financial source
 → Import / Mock / OFX
 → Data processing
 → First Financial Health
 → Home
```

## First Financial Loop

```text
Workspace
 → Account
 → Income
 → Expense
 → Balance
 → Home
```

## Import

```text
Choose file
 → Validate
 → Preview
 → Confirm
 → Async processing
 → Progress/status
 → Results
 → Updated analytics
```

## Credit Card

```text
Cards
 → Select card
 → Current invoice
 → Transactions
 → Installments
 → Future invoices
 → Utilization
```

## Insight

```text
Home/Insights
 → Insight card
 → Context
 → Evidence
 → Explanation
 → Optional action
```

## Simulation

```text
User scenario
 → Validate inputs
 → Deterministic simulation
 → Impact on cash flow/goals/health
 → Explain assumptions
 → User decides
```

## Copilot

```text
Question
 → Intent
 → Context
 → Financial query
 → Calculation
 → AI explanation
 → Sources/evidence
 → Optional simulation/action
```
