# 05.8 AI / Copilot Architecture

## Regra central

> A inteligência artificial explica e contextualiza a verdade financeira produzida pelo sistema; ela nunca substitui essa verdade.

## Tarefas

- classificação
- extração
- resumo
- explicação
- recomendação
- interpretação de simulações
- Copilot

## Fluxo obrigatório

```text
Question
→ Authentication
→ Workspace Authorization
→ Rate Limit
→ Intent Detection
→ Context Builder
→ Financial Queries
→ Deterministic Calculations
→ Context Validation
→ Prompt
→ AI Gateway
→ LLM
→ Structured Output Validation
→ Financial Claim Validation
→ Response
```

## Tool Calling

A IA usa ferramentas permitidas.
Nunca acessa DB diretamente.

## Financial Truth Layer

Todos os valores financeiros precisam ter origem rastreável.

## Structured output

```json
{
  "answer": "...",
  "type": "analysis",
  "financialData": [],
  "explanation": [],
  "confidence": "high",
  "actions": [],
  "sources": []
}
```

A confidence não deve ser apenas o que o modelo declara. Deve considerar qualidade dos dados.

## Data quality

- completeness
- freshness
- source
- confirmed/imported/estimated/simulated

## Versionamento

Versionar:
- prompts
- context schemas
- algorithms

## Prompt injection

Dados financeiros e textos importados são conteúdo não confiável, não instruções.

## Permissions

MVP:
- leitura
- simulação

Sem operações destrutivas ou gravações financeiras iniciadas pela IA.

## Memória

Separar:
- conversation memory
- financial state
- user preferences

Não criar memória financeira arbitrária de longo prazo no MVP.

## AI Usage Ledger

Registrar:
- provider
- model
- tokens
- cost
- latency
- request type
- workspace
- user

## Planos

Free: sem Copilot.
Plus: limitado.
Pro: expandido.

## Cost control

- token quota
- request quota
- daily/monthly
- model routing
- timeout
- provider fallback

## Falha

Falha de IA nunca pode comprometer Financial Core.

## Observabilidade

Registrar requests, tokens, custo, latency, validation, tools e fallback sem expor dados sensíveis.

## Golden rule

IA interpreta; o sistema calcula.
