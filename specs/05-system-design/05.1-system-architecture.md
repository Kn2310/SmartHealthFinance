# 05.1 System Architecture

## Decisão

Domain-Centric Modular Monolith.

O MVP não deve iniciar como conjunto de microserviços.

## Princípios

- limites explícitos entre módulos
- DDD quando agrega valor
- Clean Architecture
- PostgreSQL como fonte primária
- processamento assíncrono onde apropriado
- IA isolada da verdade financeira
- read models derivados
- privacy/explainability by design

## Dados iniciais

- Mock
- CSV
- OFX

Open Finance entra posteriormente.

## Fluxo

```text
Frontend
   ↓
REST API
   ↓
Application
   ↓
Domain
   ↓
PostgreSQL

Async:
Domain/Event → Outbox → RabbitMQ → Workers → Derived Read Models
```

## Regra

Não introduzir microserviço, Kubernetes ou service mesh apenas por antecipação de escala.
