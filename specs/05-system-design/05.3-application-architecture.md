# 05.3 Application Architecture

## Direção

```text
Presentation
     ↓
Application
     ↓
Domain

Infrastructure implementa portas internas.
```

## Application

Responsável por:
- orquestração
- commands/queries
- DTOs
- validação
- autorização contextual
- transações
- publicação de eventos
- comunicação externa

## Copilot

```text
Question
→ Intent Detection
→ Context Builder
→ Financial Queries
→ Deterministic Calculations
→ Structured Context
→ LLM
→ Validation
→ Response
```

Contrato interno:

```json
{
  "answer": "...",
  "type": "analysis",
  "financialData": [],
  "explanation": [],
  "confidence": "high",
  "actions": [],
  "sources": []
}
```
