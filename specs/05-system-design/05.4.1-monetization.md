# 05.4.1 Monetization Architecture

## Planos MVP

### Free
- sem Open Finance
- CSV/OFX/manual/mock
- Insights limitados
- sem Copilot

### Plus
- Open Finance
- todos os Insights
- Copilot limitado por dia

### Pro
- Open Finance
- todos os Insights
- aproximadamente 5x mais uso de Copilot que Plus

Limites e preços reais devem ser calibrados por custo.

## Arquitetura

Monetization como módulo de primeira classe:
- subscription
- plan
- entitlement
- AI usage limit/credit
- usage ledger
- billing provider abstraction

## Regras

Entitlements são checados na Application Layer antes de executar funcionalidades premium.

Custos de IA precisam ser rastreados por:
- workspace
- user
- provider
- model
- tokens
- request type

Proteções:
- quotas
- rate limits
- anti-abuse
- model routing
