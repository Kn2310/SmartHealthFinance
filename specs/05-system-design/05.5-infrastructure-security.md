# 05.5 Infrastructure & Security Architecture

## Runtime

```text
Internet
  ↓
Reverse Proxy / Load Balancer
  ├── Next.js
  └── Spring Boot API
       ├── PostgreSQL
       ├── Redis
       └── RabbitMQ
            ├── Analytics Worker
            ├── Forecast Worker
            ├── AI Worker
            └── Import Worker
```

## Backend

Java + Spring Boot:
- Spring Security
- Spring Data
- Flyway
- PostgreSQL
- RabbitMQ
- Redis
- OpenTelemetry

## Módulos

Identity, Monetization, Financial, Accounts, Cards, Transactions, Planning, Analytics, Health, Forecasting, Insights, Simulation, Ingestion, Copilot.

## API

REST, stateless quando possível, HTTPS, `/api/v1`.

## Redis

Nunca é source of truth.

## RabbitMQ

Async + Outbox.
Retry + DLQ.
Consumers idempotentes.

## AI Gateway

- provider abstraction
- model selection
- token/cost tracking
- timeout/retry
- rate limit
- structured output
- prompt versioning
- observability

## Open Finance

Atrás de `OpenFinancePort`.
Providers como adapters.
Credenciais/tokens criptografados.

## Auth

OAuth2/OIDC.
JWT mínimo.
Não colocar dados financeiros ou entitlements críticos no JWT.
Workspace authorization.

Se houver senha direta: Argon2id.
MFA futuramente.

## Segurança

- TLS
- encryption at rest
- application encryption para campos sensíveis
- secret manager
- environments isolados
- synthetic data em dev/staging
- restrictive CORS
- request limits
- file security
- no secrets in logs
- correlation IDs

## Observabilidade

OpenTelemetry para traces, metrics e logs.

## MVP

Uma aplicação + PostgreSQL + Redis + RabbitMQ.
Escalar workers/instâncias conforme necessidade.
Evitar Kubernetes no início.
