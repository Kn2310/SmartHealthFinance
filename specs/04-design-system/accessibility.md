# Accessibility

## Requirements

- keyboard navigation
- visible focus
- semantic HTML
- accessible labels
- sufficient contrast
- no color-only meaning
- screen reader friendly states
- reduced motion support
- form errors linked to fields
- loading state announced where appropriate
- responsive touch targets

## Financial data

Numbers must remain understandable without relying on color.

Examples:
- `+ R$ 1.250,00 · Receita`
- `− R$ 420,00 · Despesa`
- `Estimado`
- `Simulado`

## Charts

Charts devem possuir resumo textual ou alternativa equivalente.
